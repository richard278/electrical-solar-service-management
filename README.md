# Electrical Solar Service Management

Service management system for residential electrical and solar installations.

This platform allows managing service requests, scheduling technical visits, assigning technicians, and tracking installation work between clients and field technicians.

## Features

- Service request registration
- Technical visit scheduling
- Technician assignment
- Customer management
- Service tracking
- Work history

## Tech Stack

- ASP.NET MVC5
- C#
- SQL Server
- Entity Framework
- Bootstrap

## Domain

Field service management system for electrical and solar installation services.
